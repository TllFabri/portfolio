# Portfólio — Thiago Fabri

Meu site pessoal de apresentação: quem sou, projetos, experiência, competências, formação e contato.

🔗 **Acesse:** [tfabri.vercel.app](https://tfabri.vercel.app)

## Funcionalidades

- Layout responsivo (celular, tablet e desktop)
- Tema claro/escuro, que lembra a escolha do visitante
- Idioma português/inglês (PT/EN)
- Animação de abertura e animações ao rolar a página
- Filtro de projetos (Backend / Frontend)
- Botão para copiar o e-mail e download do currículo em PDF
- Respeita a preferência de "reduzir movimento" do sistema

## Tecnologias

- HTML, CSS e JavaScript puro (sem frameworks)
- Deploy na [Vercel](https://vercel.com)

## Estrutura

```
├── index.html               # conteúdo do site
├── style.css                # estilos e temas
├── script.js                # tema, idioma, animações e interações
├── img/                     # favicon e ícones
└── Curriculo_ThiagoFabri.pdf
```

## Rodando localmente

Basta abrir o `index.html` no navegador, ou usar a extensão Live Server do VS Code.
